# Mad Monkey Media website

Static site. Pages are generated from `content/*.json` by `tools/gen.py`. Vercel runs `python3 tools/build.py` on every deploy and serves `dist/`.

## Editing content
Open `https://themadmonkey.in/admin`, sign in with a GitHub token, edit, and press Publish. The change goes live in 1-2 minutes.

## Layout
- `content/` page text, portfolio list, FAQ, stats (edited through /admin)
- `admin/` the admin panel (`config.yml` is generated by `tools/make_cms_config.py`)
- `tools/gen.py` page templates, `tools/build.py` build script
- `assets/` images and videos, `styles.css`, `script.js`
